# TTSTextReader

고품질 AI TTS 기술을 활용한 오프라인 텍스트 뷰어 앱입니다.

## 주요 기능

- **고품질 오프라인 AI TTS** — ONNX Runtime 기반으로 인터넷 없이도 자연스러운 AI 음성 지원
- **다중 엔진 비교** — 시스템 기본 TTS와 AI 엔진을 한 화면에서 즉시 비교·전환
- **한글 특화 전처리** — 숫자, 단위, 전화번호 등을 정확한 한국어 발음으로 변환
- **텍스트 & EPUB 뷰어** — 대용량 텍스트 파일과 EPUB 전자책을 부드럽게 표시
- **이어읽기** — 파일별 읽기 위치 자동 저장, 언제든 이어서 듣기
- **다크/라이트 테마** — Material 3 기반 테마 지원
